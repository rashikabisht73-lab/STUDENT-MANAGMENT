# 🎓 Student Management System

A simple website to add, view, search and delete student records.
Built with **HTML, CSS and JavaScript** only — no server, no paid services.

## Features
- Add a student (name, course, email)
- View all students in a table
- Search students
- Delete a student
- Data is saved in the browser (localStorage), so it stays after refresh

## Files
| File         | Purpose                          |
|--------------|----------------------------------|
| `index.html` | Page structure (form + table)    |
| `style.css`  | Colours, layout and design       |
| `script.js`  | Adding, showing, deleting data   |

## How to run
Just double-click `index.html` to open it in your browser.
